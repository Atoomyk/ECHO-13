# PULSE — аркада на одну кнопку

Минималистичная чёрно-белая аркада: белая точка в центре экрана, от краёв к ней
сжимаются концентрические кольца. Единственное действие — импульс, который
отбрасывает кольца и тратит энергию. Всё остальное время энергия восстанавливается.

Проект независим: собственное ядро, собственный сервер рекордов, собственный деплой.
Зависимостей нет — ни на клиенте, ни на сервере, `npm install` не требуется.

## Быстрый старт

Node.js **22.5+** (нужен встроенный `node:sqlite`).

```bash
npm start          # http://127.0.0.1:3002 — игра, API и статика в одном процессе
npm run dev        # то же с автоперезапуском
npm test           # 73 теста ядра и API
npm run smoke      # 16 проверок живого сервера: маршруты, статика, зашита от обхода путей
```

Переменные окружения — в локальном `.env` (в git не попадает): порт, адрес, путь к базе, домены для CORS.

## Правила

| Событие | Что происходит |
| --- | --- |
| Нажатие (клик / тап / пробел / Enter) | импульс отбрасывает все кольца ближе `PULSE_REACH` |
| Отбитое кольцо | улетает за пределы поля и больше не угрожает |
| Кольцо без разрыва дошло до центра | урон, короткая неуязвимость, множитель падает |
| Рваное кольцо прошло через разрыв | «чистое уклонение»: множитель растёт |
| Энергия дошла до нуля | партия окончена |

Счёт — время выживания, умноженное на множитель. Множитель растёт только за чистые
уклонения: пассивно пересидеть партию нельзя, а «дырка = тайминг» становится смыслом игры.

### Прогрессия

Кольца ускоряются ступенями (каждые четыре кольца), интервал появления сокращается,
урон и стоимость импульса остаются постоянными. По времени партии включаются типы:

| Секунда | Тип |
| --- | --- |
| 0 | сплошные кольца |
| 60 | двойные: два слоя с разными разрывами |
| 90 | рваные: один вращающийся разрыв |
| 120 | магнитные: ускоряются, входя в зону притяжения |

Пороги берутся из профиля дня, поэтому у всех игроков челленджа они одинаковые.

## Ежедневный челлендж

В 00:00 UTC меняется сид: `pulse-YYYY-MM-DD` (`src/core/random.js`). Сид влияет и на
разброс скорости колец (±12%), и на их форму, поэтому у всех игроков дня паттерн общий,
а между днями — разный. Результат шарится эмодзи-сеткой: 🟢 чистое уклонение,
🟡 спокойный участок, 🔴 касание кольца.

## Управление

- мышь и тач — нажатие в любом месте поля;
- `пробел` / `Enter` — импульс;
- `Esc` / `P` — пауза;
- `prefers-reduced-motion` отключает пульсацию точки.

## Архитектура

Ключевое решение: **правила не зависят ни от DOM, ни от таймеров**. `src/core` — чистый
ES-модуль, который импортируют браузер, тесты и сервер. Симуляция идёт фиксированным
шагом 120 Гц, поэтому партия воспроизводима по одному сиду и одной последовательности
нажатий — это и есть основа честного челленджа дня.

```
pulse/
├── index.html            разметка поля, HUD, меню, экранов
├── styles.css            тема: чёрный фон, белый свет, моношрифт
├── src/
│   ├── core/             правила — без DOM и Node API, покрыты тестами
│   │   ├── constants.js  весь баланс в одном месте
│   │   ├── random.js     seeded PRNG и сид дня
│   │   ├── ring.js       кольцо: радиус, разрыв, магнит
│   │   ├── player.js     энергия, множитель, неуязвимость
│   │   ├── game.js       цикл партии фиксированным шагом
│   │   └── result.js     итог партии и эмодзи-сетка
│   ├── ui/
│   │   ├── render.js     Canvas 2D: свечение, частицы, инверсия экрана
│   │   ├── sound.js      Web Audio: гул, blip по пентатонике, шум удара
│   │   ├── input.js      мышь, тач и клавиатура — в одно событие «импульс»
│   │   └── api.js        сеть и localStorage, ошибки сети не ломают партию
│   └── main.js           связывает ядро, рендер, звук и интерфейс
├── server/
│   ├── server.js         HTTP: API, статика, graceful shutdown
│   ├── app.js            валидация и ответы — чистые функции
│   ├── store.js          SQLite (с откатом на JSON)
│   ├── static.js         раздача файлов с защитой от обхода путей
│   └── config.js         настройки из переменных окружения
├── scripts/smoke.js      проверка живого сервера
├── deploy/               nginx, systemd, install.sh
└── test/                 ядро, API и геометрия (node --test)
```

### Почему Canvas 2D, а не WebGL-шейдеры

Цель — 60 FPS на телефоне 2020 года и сервер на 768 МБ. Свечение сделано несколькими
проходами с падающей альфой: это дешевле размытия, не требует WebGL и одинаково
работает на слабых GPU. Частицы берутся из пула — в кадре нет аллокаций.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/health` | состояние сервиса, тип хранилища |
| GET | `/api/daily` | сид дня, дата и пороги сложности |
| GET | `/api/leaderboard?mode=daily&limit=10&player=Ник` | таблица рекордов + место игрока |
| POST | `/api/scores` | сохранить результат |
| GET | `/api/stats?mode=free` | число партий, лучший и средний счёт |

Ограничения: имя до 24 символов, тело запроса до 2 КБ, `limit` от 1 до 100, режимы —
`free` и `daily`. Управляющие символы вырезаются, имена рендерятся через `textContent`,
поэтому разметку внедрить нельзя.

Счёт проверяется на правдоподобность: он не может превышать
`время × 10 × максимальный множитель`. Это не защита от читов (клиент по-прежнему
может прислать любой достижимый счёт), а отсечение заведомо невозможных значений.

## Развёртывание на 1 vCPU / 768 МБ

```bash
sudo bash deploy/install.sh /path/to/pulse
```

Скрипт ставит nginx и Node 22, создаёт пользователя `pulse`, раскладывает статику в
`/var/www/pulse`, сервер — в `/opt/pulse`, базу — в `/var/lib/pulse`, включает systemd
и проверяет `/api/health`.

Схема под этот сервер:

- **nginx** отдаёт статику (десятки МБ RSS) и проксирует только `/api/` в Node;
- **Node** — один процесс, `MemoryMax=256M`, `CPUQuota=80%`, автоперезапуск;
- **SQLite** в WAL-режиме: один файл, без отдельного сервера БД и его памяти;
- **нет** `node_modules` и шага сборки — экономит и диск, и память.

CDN не обязателен: вся сборка — это `index.html`, `styles.css` и десяток ES-модулей,
суммарно меньше 100 КБ. Если ставить Cloudflare или Bunny, достаточно направить их на
nginx и не кэшировать `/api/`.

### Важно при правке файлов в Windows

Скрипт `deploy/install.sh` должен иметь переводы строк **LF** и **не иметь BOM**, иначе
shebang `#!/usr/bin/env bash` перестанет распознаваться на Linux. Проверка перед деплоем:

```bash
file deploy/install.sh          # ожидается: ASCII text (не "with BOM")
bash -n deploy/install.sh       # синтаксис
```

## Баланс

Все числа собраны в `src/core/constants.js`. При их правке полезно держать в голове
три соглашения, на которых держится игра:

1. **импульс обязан спасать** — отбитое кольцо помечается `resolved` и больше не бьёт,
   иначе отброс лишь отсрочивает удар;
2. **окно реакции** — кольцо идёт от границы `PULSE_REACH` до центра около секунды,
   за это время игрок успевает нажать;
3. **кольца не копятся** — при интервале появления в поле одновременно живёт 1–2 кольца,
   иначе одно нажатие физически не покрывает угрозы.

## Известные ограничения

- нет аккаунтов: имя игрока вводится вручную и хранится в `localStorage`;
- рекорды не проверяются криптографически — для аркады без авторизации это осознанный
  компромисс, сервер лишь отсекает невозможные значения;
- звук синтезируется на клиенте, поэтому тембр зависит от браузера;
- `node:sqlite` в Node 22–24 помечен экспериментальным: в логах есть
  `ExperimentalWarning`. Модуль стабильно работает, при обновлении Node стоит проверить.
